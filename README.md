# Python Basic Tasks 🐍

This repository contains five beginner-friendly Python programming tasks covering variables, input/output, conditional statements, arithmetic operations, and string manipulation.

## 📚 Tasks Included

1. **Hello World by Your Name**
   - Takes the user's name as input.
   - Displays a personalized Hello World message.

2. **Profit or Loss Calculator**
   - Takes Cost Price and Selling Price.
   - Calculates whether there is a profit, loss, or no profit/loss.

3. **Odd or Even Number**
   - Takes an integer as input.
   - Checks whether the number is odd or even.

4. **Voting Eligibility**
   - Takes age as input.
   - Checks whether the age is valid and whether the person is eligible to vote.

5. **Anagram Checker**
   - Takes two words as input.
   - Checks whether the two words are anagrams.

## 🛠️ Technologies Used

- Python 3
- `if`, `elif`, `else`
- Variables
- User input
- Arithmetic operators
- Modulus operator (`%`)
- `sorted()` function
- String methods

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

```bash
python basic_tasks.py
```

On some systems, use:

```bash
python3 basic_tasks.py
```
